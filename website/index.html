End-to-End Encryption

中间人只能看到乱码

手机和电脑之间的消息，要经过服务器转发。但转发服务器只能看到加密后的乱码——你的聊天内容、文件路径、审批操作，它一样也读不到。

📱

你的手机

发送前加密

消息在离开手机之前就已加密。扫码配对时记住了你电脑的"钥匙指纹"，以后每次连接都先核对，防止有人冒充你的电脑。

转发服务器
只见乱码 · 无法解读
🖥️

你的电脑

收到后才解密

解密钥匙只存在你电脑本地，不写进界面、不发给任何程序——连桌面应用的界面代码都拿不到它。

第一道防线

冒充不了

第一次扫码时，手机就记住了电脑密钥的"指纹"。之后哪怕有人架起假服务器、假电脑，对不上指纹，手机直接拒绝连接。

第二道防线

篡改不了

每条消息都带"防伪封条"，封条覆盖了消息内容和收件地址。转发服务器想偷偷改个目标、改一个标点，电脑收到后立刻发现并丢弃。

第三道防线

重放不了

就算有人录下一段加密消息、原样重发一百遍，每条消息都有唯一编号，见过的编号再出现就直接扔掉，不会被执行两次。

    Quick Start

    三步，开始远程

    不需要公网 IP、不需要 Docker、不需要懂加密。

    1

    桌面端开启远程

    安装 Windows 版，在「设置 → 消息渠道 → 自建托管」打开开关。默认 局域网模式，内置 Relay 一键可用。

    2

    手机扫码配对

    安装 Android APK，扫描电脑屏幕上的配对二维码。一次性 token 换发长期凭证，X25519 公钥同步钉扎。

    3

    随时连回

    在公司、在地铁，4G / 5G 直连你的云 Relay。会话按项目分组，聊天、审批、插队全在手机上。
